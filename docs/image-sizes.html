Keep all four at exactly 2.4 : 1. Desktop screens crop the left and right edges; phones show only a tall slice, so keep the model and the jewellery in the left-centre third of the frame. Export rules for the team

  1. Export photos as WebP, quality about 80. Aim for under 300 KB at 3840 × 1600.
  2. Keep the original high-resolution masters (JPEG or PNG) outside public/; only the web exports go on the site.
  3. Name replacements the same as the current files (festival-01.webp to -04) so no code changes are needed.
  4. Order: 01 wide shot, 02 pendant, 03 earring, 04 ring.
